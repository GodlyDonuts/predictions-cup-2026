# Local paper dashboard

Next.js read-only dashboard at http://127.0.0.1:3000. The default Official account tab displays actual tournament positions, valuation P&L, the newest 100 fills, and open orders made by this account on the official platform. Independent scaled/conservative paper wallets remain separate tabs. It refreshes local statistics every five seconds; browser refreshes never contact the trading platform.

Run `pnpm install --frozen-lockfile`, `pnpm build`, then `pnpm start` from this directory, or use `Start-Dashboard.ps1` after installation/build. Keep the collector on port 8787 running. The launcher enables `official-sync.json` in the restricted runtime; restart an existing collector once to load this setting. The server binds only to the PC loopback interface. No API credential is required or read by this application. Its only route fetches three fixed local read endpoints and returns curated statistics. It has no trading controls.

Official account sync reuses existing position/open-order reads. One of the two historical read slots is replaced with a rotating GET for fills, daily P&L, or recent order history. It uses the same serialized six-second pacing, persistent cooldown and account budget. The display is a sampled snapshot, not a realtime transaction feed: each section shows its last successful sync, errors preserve older snapshots, and extra fill pages are explicitly indicated. A fill's BUY/SELL action is joined from its matching order when known, otherwise shown as FILL; signed quantity determines YES/NO, never BUY/SELL. No raw account responses enter logs, the paper journal or GitHub. Account projections remain only in restricted LOCALAPPDATA. Tournament valuation values are separate from executable liquidation values.
