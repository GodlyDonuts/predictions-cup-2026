# Baal measured Senate polling errors and one paper strategy

Primary historical input: [FiveThirtyEight's own polling archive](https://github.com/fivethirtyeight/data/blob/master/pollster-ratings/raw_polls.csv) and [codebook](https://github.com/fivethirtyeight/data/blob/master/pollster-ratings/README.md). File Git blob IDs and SHA256 hashes are verified on capture. Raw files remain in the restricted local runtime. Final candidate identities and vote shares are independently checked against the corrected MIT/FEC Senate source used by V2. No future pollster rating enters a forecast.

The frozen baseline has185 race observations across13 election cycles, from1998 through2022. Each race has total weight one. Duplicate questions and repeated releases cannot buy a pollster extra weight. A fixed45-day forecast cutoff and30-day poll-age window select the latest eligible median field date per pollster. The2020/2022 chronological diagnostic contains18 covered races; the poll-centered family got17 directions right, with Brier0.06815. This is a retrospective outcome diagnostic with revised data, limited coverage, absent original publication clocks and only two diagnostic election cycles. It supplies no historical executable prices or trading profit. `frozen-model-baseline-20261005.mjs` preserves the exact source hash that produced that report; `train.mjs --verify` reproduces it without overwriting artifacts.

A current single poll uses the dispersion of individual polls, including disagreement within a race. It must not borrow the smaller error of a historical pooled average. The named single-poll model covers491 pollster/race observations with equal total weight for each of185 races. Its historical error SD is7.9206 margin points. Historical bias, a fixed Student-t4 distribution and leave-one-election-cycle parameter sensitivity give a Kansas Democratic valuation range0.600319–0.643157 after a judgment2-point haircut. This range is not a confidence bound or guaranteed settlement payout. An additional adverse3-point margin-shift stress yields about0.42548; turnout and fieldwork-age risks remain visible. Historical population labels are absent, so a specific LV/RV adjustment is unmeasured.

Current source facts retain the original [Kansas Emerson September15–16 likely-voter poll](https://emersoncollegepolling.com/kansas-2026/) and verified [general-election ballot](https://meadeco.org/367/2026-General-Election-Information), linked from the immutable current-polls evidence. The newer [Iowa Marist table packet](https://maristpoll.marist.edu/wp-content/uploads/2026/09/Marist-Poll-IA-NOS-and-Tables_202609211631-1.pdf) confirms registered-voter Senate results; no likely-voter estimate is invented from it. This paper cohort only targets Kansas market356 YES/exchange1045 after exact official contract-root verification. Source observation clocks, original fieldwork, the current assessment and subsequent quote clocks remain distinct.

The prospective cohort `calibrated-kansas-poll-20261005-v1` has an immutable future cutoff, independent wallet journal and zero opening inventory. It uses the existing receipt paper engine: one share,1% depth, one adverse tick, zero fees,1/3-second latency variants, a2-cent profit target and5-cent loss threshold, with subsequent-request fills and fresh account exclusions. Latency variants share opportunities and are not independent samples. Expected election value does not imply that a profitable short-term sale will occur. Net realized and depth-aware liquidation P&L, open risk and unavailable exits must all remain visible.

The existing paper worker hosts this cohort alongside the prior frozen wallet, whose original inventory/accounting is preserved. The single serialized collector merges their read hints, retains held risk first and replaces existing read slots; no account client, key or persistent service is added. No contest order, production-bank change or entry-window extension is created by this experiment. The original official pilot remains expired. Production deployment must use actual strategy economics rather than relabeling these diagnostic scores as profit.
