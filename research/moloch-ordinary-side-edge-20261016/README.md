# Ordinary paired-spread side criterion

Task [155](https://github.com/GodlyDonuts/predictions-cup-2026/issues/155). This runtime selection hypothesis is not a calibrated forecast or demonstrated positive EV. The native financial policy, order prices/quantities, source clocks, sixty-second execution-age rule and physical-account authority remain unchanged.

The native `pairedSpread` planner checks the combined YES/NO discount but ordinarily submits its legs separately. Its existing per-side microprice edge criterion applies to `microprice` mode and inside-price improvement, rather than every zero-inside-tick paired-spread leg. A passive one-sided fill can therefore have little contemporaneous depth-weighted side edge even when the combined discount is positive.

The new optional control field is `"ordinarySideEdge":"disabled"`, `"shadow"`, or `"enforce"`. Omission defaults to **disabled**, which performs no assessment or diagnostic IO. Shadow records the actual assessment and continues the original dispatch path. Enforce defers an ordinary unhedged BUY if its side edge is below the original native policy minimum, or if the required evidence is unavailable. Changing this field requires the execution owner's separately reviewed control/binary binding; shipping source does not enable it. No threshold, fee or monetary-cap override is added.

The assessment runs after the original final seven-receipt preflight, native quote/cancel/expiry checks and fresh quote priority. It uses that unchanged original book receipt and `bank.engine().policy()`. The existing cursor and one-preflight budget have already advanced; deferral returns without spending a second packet or creating an intent/attempt. SELLs, packages and reviewed fundamental cohorts bypass the criterion. A wholly covered opposite BUY also bypasses when actual native opposite inventory covers the **entire remaining frozen BUY** after other outstanding netting BUYs and opposite SELL pledges; partial coverage does not clip the quote or bypass the criterion. Retired-but-physically-unclosed attempts remain encumbrances. This bypass grants no profit, fill, funding or retry authority.

Arithmetic matches the native planner: `YES micro = floor((YES ask × YES bid quantity + YES bid × YES ask quantity)/(bid quantity + ask quantity))`; NO value is exactly `1 − floored YES micro`. Side edge is that value minus the unchanged BUY limit minus the native `fee(limit,1)` ceiling. It is compared inclusively against the actual policy's `minimumEdge`. For example, YES bid .400×10 and ask .410×990 imply YES proxy .400100. A .400 BUY has only .000100 side edge at zero fees despite a .010 combined pair discount. The complementary .590 NO bid has .009900 proxy edge. Neither figure promises either order will fill or predicts its future executable value.

The original REST endpoint, tournament/market/exchange coverage, status, ordered nonempty depth, integer sizes, tick prices, source sequence and source/request/receipt clocks must validate. Every scoped exchange in that market must be present without duplicates. All three clocks retain their original values and the actual native `bookAgeMs` bound. Missing, malformed, future, stale, incomplete or overflowing evidence is explicitly unavailable. No price, depth or clock is fabricated. The original book receipt, exact native quote and policy hashes are recorded on valid assessments.

`ordinary-side-edge.json` is a bounded latest-assessment diagnostic, including mode, classification and native head; it is not an immutable audit of every historical decision. Diagnostic writes are best effort, so a shadow logging failure cannot change legacy trading. Enforce still defers a failed/unavailable criterion if that diagnostic write fails. Original dispatch/account journals remain authoritative.

Parent's finite genuine capture labels show only nine fully depth-supported one-second observations. This proposed submission filter separates two observations totaling −24.34 from seven totaling −3.90 at one second; the kept seven are still −6.71 at120seconds. These are retrospective conditional labels, not counterfactual executions or a qualified strategy. Most older fills have no capture label and are not imputed. The finding motivates a prospectively declared comparison; it does not establish profit or justify increasing size, extending age or claiming that rejected orders would have filled differently.
