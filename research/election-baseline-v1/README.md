# Historical election-margin baseline

This regularized model predicts Republican two-party Senate vote margin from strictly earlier presidential state lean, the same seat's prior regular election, and inferred incumbent identity. It uses MIT Election Lab's CC0 Senate1976–2024 and president1976–2024 datasets, original CSV downloads with verified published checksums. Source versions and hashes are preserved in `sources/*-manifest.json`.

Run `node research/election-baseline-v1/download-sources.mjs`, the model tests, then `node research/election-baseline-v1/train.mjs`. Original result files are immutable. The full local model report hash appears in `model-summary.json`; the script reproduces the fit from the published source manifests. The original CSVs remain local and publicly downloadable rather than duplicated in this repository.

Lambda1 was selected using expanding-cycle development data through2018. Separate2020/2022/2024 chronological checks contain79 screened races:73 correct directions,10.04 percentage-point margin RMSE, Brier0.06758. These are historical outcome checks, not historical market trades. Revised final-result datasets and final nominee identities are not original October forecast vintages. These check results are now observed; subsequent changes cannot reuse them as untouched validation.

The model excludes independent winners and material third-party races. Its probabilities are conditional on the screened two-party contest design. West Virginia's official2026 ballot includes a Constitution Party candidate, so a Republican-versus-Democrat margin range does not by itself establish the unconditional Republican Party contract probability. The current national generic-ballot adjustment is also unvalidated transport from a different election target. No supplied scenario minimum is a calibrated confidence floor. Neither draft is qualified for production.

Current input publication clocks are preserved; source expiry follows the polling publication, not model fitting or page retrieval. `current-inputs.json` contains original draft aliases. Subsequent official ballot and contract facts are recorded separately in `source-crosschecks.json`. No current bank, wallet, accounting history or contest order was changed to obtain these results. Fees remain zero; profitable executable pricing is a separate requirement.

Primary source datasets: [Senate](https://doi.org/10.7910/DVN/PEJ5QU), [president](https://doi.org/10.7910/DVN/42MVDX). Official numerical cross-check: [FEC2024 presidential general results](https://www.fec.gov/documents/5644/2024presgeresults.pdf). Current ballot: [West Virginia Secretary of State2026 Nicholas County sample](https://apps.sos.wv.gov/elections/2026GeneralSampleBallots/SAMPLE%20-%20WV%20Nicholas%20261103%20General%20-%2014inch.pdf).
