The same paper worker and four-book collector budget serve all cohorts; each latency wallet is a correlated counterfactual, not independent evidence.

This experiment uses it as an **unvalidated governor proxy**, widens dispersion to at least12 margin points, retains cycle omissions, explicit RV turnout/rounding sensitivity and a2-point administrative probability haircut. Severe remaining-support allocation lowers the estimate to0.224875; additional governor transport shifts are shown separately. Pollsters may share systematic errors, and current polling cannot guarantee the result.
