## Boundaries checked

- **One source and writer.** [`LivePreflightReads`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/live-runtime/src/worker.rs#L1084) borrows the existing Transport, Realtime, capture and universe. Before each logical preflight GET it checks stream/control, drains already queued frames through the same mutable Session/RestSource, then checks stream/control again. It creates no client or concurrent bank writer.
- **Source order and coverage.** [`drain_stream`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/live-runtime/src/worker.rs#L1384) preserves queued frame order and the existing 64-frame/32-event bounds. Prior valid pending source events are flushed before a later error propagates. Existing [`RestSource::broadcast`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/native/src/source.rs#L546) still invalidates on delivery gaps/resync/unsequenced trades and preserves complete-tape recovery requirements; the hook does not assert coverage or reset a gap.
- **Older REST response.** [`RestSource::apply`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/native/src/source.rs#L386) compares sequence/source time before replacing its cached book. A serviced newer WS version can therefore survive an older final REST response without a native rollback. The existing normalizer can emit that cached version with the later receipt time; it retains the cached source/request clocks. The new hook does not change this behavior or rewrite the seven original physical Receipts.
- **Exact quote, not head.** [`preflight_read`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/live-runtime/src/worker.rs#L1026) checks the same genuine qid and full quote after service, including retirement/cancellation/expiry. A changed quote returns a private typed defer before the next GET. Arbitrary errors with the same display text propagate. Head-only progress is allowed. [`ordinary_preflight`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/live-runtime/src/worker.rs#L1130) also compares the final actual quote after book admission; it does not replace a frozen qid, price, size or expiry.
- **Reviewed planning.** Preliminary existing-inventory/forecast packets have no funded quote to freeze. They obtain facts, admit the actual book and recheck liabilities before constructing their existing opaque plan. There is no new hook between plan validation and native acceptance. The final reviewed-entry packet additionally binds the reserved actual quote; source invalidation defers it. Original source-review, depth, freshness and physical authority checks remain in place.
- **Fill and intent ordering.** [`snapshots_for_market`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/live-runtime/src/worker.rs#L330) retains Tournament → Positions → open Orders → Account → Market → Nodes → Book order. The callback runs only before a read. Existing owned-fill reconciliation still validates/applies the returned complete tape and commits terminal state without an intervening hook. [`submit_order`](https://github.com/GodlyDonuts/predictions-cup-2026/blob/2225b1efba5a16078cea875f5162f96742514d3a/moloch/live-runtime/src/worker.rs#L706) retains original authority, intent, attempt, unknown-acceptance and no-retry barriers.

## Evidence and limits

Parent reported **89/89 actual ARM64 worker tests passed at 15:39:51 UTC**, including complete-seven-receipt success through genuine benign broadcasts, fatal failures before GET1/GET3, actual first-paired-quote cancellation without a GET/intent, read-only draft changes, and the existing returned-fill/terminal ordering tests. The first 88/89 run exposed a fixture divergence: native book injection had bypassed RestSource and the planner cancelled the NO mate before the selected YES quote. The corrected fixture uses genuine broadcast normalization and the actual first generated quote. Production guards were unchanged. [Check/source handoff](https://github.com/GodlyDonuts/predictions-cup-2026/issues/157#issuecomment-6219067941).

This is not a loop-speed or profitability result. A bounded drain may itself consume time and stale an earlier fact; original freshness/expiry checks must defer rather than extend clocks. The hook cannot run inside synchronous HTTP, SDK pagination/backoff, activation waits, frozen-plan acceptance or fill-application regions. Cancellation/cohort packets and other non-preflight reads were not expanded by this change.

After promotion and confirmed fresh readiness, compare a finite matching-PID suffix: original source/receipt-to-observer lags, completed scope/pass counts, exact intent/ACK clocks, and typed preflight invalidation/freshness deferrals. Receipt-to-next-request gaps include local service and SDK pacing, so they do not isolate either component. The original 777-book probe lacked append clocks; it does not prove all observed lag was caused by preflight. No new production measurement, SSH, account request, compilation or live mutation was performed for this review.
