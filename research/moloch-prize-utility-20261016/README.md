# Paper6: conditional whole-account prize utility

`moloch/live-runtime/src/prize_utility.rs` implements an **offline scoring path**, not an execution policy, ranking posterior, calibration claim, or prize/leaderboard fetcher. No prizes, balances or win probabilities from Paper6 are hardcoded. The input prize ladder and tie policy must come from a separately reviewed, source-bound artifact. A caller cannot turn a positive score into a reserve event or physical order.

## API and actual accounting scope

`Reviewed::load(originalBytes, expectedRawSha, approvedReviewHashes, approvedSourceHashes, originalSources, now)` creates an opaque review only after exact original-byte/allowlist, source-age, scope, bounded-shape and mass checks. Required original source kinds are `prize_rules`, `leaderboard_observation` and `opponent_projection`; positive debt additionally requires `terminal_liability_terms` and an explicit fixed-terminal-debt assumption. These original hashes attest retained bytes and owner review, not server authenticity or a correct opponent model. There is no self-approval or refresh of an old observation clock.

`evaluate(bank, ordinaryLog, scope, boundSurface, compiledSemantics, actualPlan, actualPolicy, retainedAccountEvidence, reviewedUtility, now)` returns `Available{score}` or explicit `Unavailable{reason}`. Existing opaque probabilistic Plan, Policy, BoundSurface and Compiled validators remain intact. Original account, complete positions, empty complete open-orders and collateral receipts must be held through the existing opaque `RetainedReceipt` file/digest/descriptor checks, scoped to the original runtime root and no older than20s. Actual cash must equal `authority::reconciled_expected_cash(bank)`. The current account profile must equal the original bank-seed account receipt profile (and owner-capital bankScope.profileId when present), with exact original endpoint/status/tournament, UUID and seed cash/clock identity. The historical original receipt is looked up using immutable seed.accountSnapshotHash through the existing opaque retained-source factory; it is identity evidence, not a newly fresh account snapshot, so the20s packet-age rule is not applied to it. Missing original identity evidence withholds scoring.

Every official position must match actual bank quantities and remaining original FIFO cost curves, including inherited holdings; missing/foreign/mismatched holdings withhold the score. Official lot IDs, side, quantity, entryPrice and original openedAt are checked. Adjacent same-price lot splits may be coalesced when economically identical. Different prices with the same original timestamp are ambiguous and withhold the score; no lot-ID ordering assumption is invented. Rounded aggregate costBasis is ignored in favor of original lot prices. Nothing rebases/adopts or mutates the bank. Pending reserved cash, open orders, package protection/uncertainty or ordinary unresolved attempts withhold the score rather than treating liabilities as absent.

For every exact joint semantic state:

```text
baseline wealth  = reconciled official cash + payouts of ALL actual held lots − verified outstanding debt
candidate cash   = baseline cash − full fixed-limit BUY principal − explicit plan fees + covered SELL proceeds
candidate wealth = candidate cash + payouts of ALL remaining/new actual-model lots − the SAME debt
```

Cash already reflects past acquisitions, realized profit and contributed principal. Starting capital and owned cost are **not added/subtracted again**. Reserved cash is not a separate terminal loss: this initial implementation requires a physically quiet, unreserved boundary instead of modeling future resting-order execution. SELL proceeds cannot fund gross BUY obligations. SELLs consume actual FIFO lots; refund states return the remaining original attributable principal, including new BUY principal, while explicit fees remain spent. Existing `semantic_states::PayoutRule` supplies the exact0/1/refund economics; YES/NO are not inferred from titles. A new opposite holding requiring venue auto-net accounting is unsupported and unavailable, not silently summed.

The existing optimizer explicitly labels its own wealth as a reviewed **sleeve plus cash**, excluding unrelated holdings/debt. This module deliberately does not reuse that metric. It rebuilds all account wealth. Every nonempty held exchange must appear in the same genuine joint state matrix. Current Compiled semantics are limited to six contracts; the current larger production portfolio therefore **cannot** obtain a whole-account score from a six-contract surface. Missing whole-account coverage returns `PRIZE_UNMODELED_HOLDING`. No independent per-sleeve probabilities or products are substituted to bypass this limitation.

The Plan adapter can initially score only plans generated by the existing expected-increment optimizer. It does not make that optimizer enumerate negative-expected-wealth/high-prize-convexity candidates or change its CVaR/funding gates. The pure scoring tests demonstrate why prize preference can differ, but completing the tournament search requires a separately checked candidate-enumeration/integration change after full portfolio and opponent evidence exist.

## Explicit joint opponents and robust comparisons

Each review declares1–32 alternative threshold models. Every model contains joint atoms `{id,stateId,weightPpm,opponentWealth}`: a semantic election state and a **conditional joint vector** of opponent terminal wealth, not independent marginal threshold draws or today's balances relabeled terminal. The declared field contains1–128 opponents; `completeOpponentField:true` is a separately reviewed modeling assumption, not a proof from a list. Larger/incomplete fields are unsupported. Original source-backed projections and scope are required; actual official leaderboard schema parsing and projection calibration are not implemented here.

Each model's atom mass is exactly1,000,000, and its aggregated marginal for **every original semantic state** must equal the immutable BoundSurface/Compiled mixture mass, including separately reviewed exceptional states. Thus changing opponent assumptions cannot quietly alter our own election posterior. No averaging across stress models or marginal-univariate multiplication occurs. Within each atom, rank is computed against all declared opponents; ties follow the explicitly reviewed `splitOccupiedPrizes` or `loseTies` rule. Split prizes retain exact rational micro-prize amounts without guessing a rounding convention. Overflow or malformed mass is unavailable.

For the same original cash/holdings/state under each model, output includes baseline expected prize, candidate expected prize, incremental expected prize, strict probability of beating the largest opponent wealth and separately the probability of tying it. The robust metric is the **minimum incremental expected prize across declared models**, not the minimum candidate prize minus an unrelated worst-case baseline. `robustPositiveInDeclaredModels` only describes that declared finite set. It is neither guaranteed profit nor a probability calibration claim; output always says `executionAuthorized:false` and `calibratedProbabilityClaimed:false`.
