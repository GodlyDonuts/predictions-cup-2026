# One shared universe model, bounded candidate subsets

The new [research projection](../../moloch/tartarus/scenario_projection.py) lets candidate batches share the same declared joint model. Regenerating scenarios separately for each subset could change the sampled held-account baseline and dependence while comparing candidates. Projection keeps every supplied held contract, every original probability-model weight and every supplied state-dependent opposing threshold, then applies the existing lossless coalescer. It retains the original matrix/model/field hashes and omitted candidate scope. Independent account compilation must still prove that the supplied holding list and liabilities are complete.

The party compiler's defaults remain64 contracts and128 scenarios. Explicit research arguments allow up to512 contracts/4096 rows; they add no live authority. Native dimensions are unchanged. A missing held contract, inconsistent original payout scope, unmodeled latent row field or projected output exceeding128 rows rejects. Five new projection tests plus the14 existing compiler/coalescing checks pass.
