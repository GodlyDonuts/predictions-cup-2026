The live population037 source remains frozen and its checkpoints are retained. An explicit `training_chunk_transitions` option now sizes future online-PPO chunks according to remaining active worlds. With64 target transitions and an eight-step minimum,8/4/2/1 active worlds produce8/16/32/64 steps per optimizer batch. A full-world finish can make the actual count smaller. This is compute organization: it does not skip decisions, force WAIT, shorten simulated days, alter API limits, restart wallets, or change the human's daily-growth reward. Longer chunks change the optimizer schedule and cannot be represented as identical learning trajectories. Old configurations keep their original behavior. Closed-episode return training cannot silently adopt this online profile.
