# Quiet-market state at episode startup

The opt-in `role_prefix_initial_state=true` restores earlier hidden exchange state and server-side read targets from the same authorized information role. It requires the observed-snapshot clock mode. Existing configurations, including active run012, remain unchanged.

Previously only the short burn-in interval initialized the world. Quiet books disappeared even when a preceding snapshot existed in the authorized training role. The new initializer replays that role's preceding book/gap state and preserves earlier external reference read targets. It retains original source ages and invalidations. It imports no actor prices, trade prints, policy memory, orders, wallets, fills or rate admissions. Actor observations still require charged reads or the configured stream protocol. Later-role receipts and snapshots whose world clocks precede the current role remain excluded.
