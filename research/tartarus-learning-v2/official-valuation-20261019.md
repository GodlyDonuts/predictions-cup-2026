# Official tournament valuation alongside replay midpoints

`moloch.learning_actions.official_marks` now provides a causal official-mark tape, exact valuation and `OfficialGrowthLedger`. This reuses the human's daily log-growth/consistency/economic-event reward while replacing midpoint valuation with explicitly sourced tournament-position prices. It is an optional, separate adapter; running phase013 keeps its original pinned midpoint convention. Missing official values never become zero, cost basis, last trade, external prices or a midpoint fallback. Missing valuation does not reject orders, alter masks or narrow the trading universe.

The official participant documentation distinguishes tournament `valuation_price` in portfolio positions/P&L from the isolated order-book quotes and latest trade available through exchange-price endpoints. A quote or global price is insufficient evidence of a tournament valuation. See the [official API documentation](https://sig.thesuper.market/api/v1/docs), `/tournaments/{slug}/portfolio/positions`, `/tournaments/{slug}/portfolio/pnl` and `/exchanges/{id}/price`. The retained October19 OpenAPI canonical hash is `fbdf23e54d317392f9fb4a659b9511a01fad065e7a384f28091ef04894a732c9`.

## Original receipt evidence

The read-only source audit recovered24 original successful position receipts in the existing inspected train/evolution calendars. Their raw byte hashes and original Rust Receipt semantic filename digests verify locally. The private48,304-byte compressed archive has SHA256 `421ea5b294e0da324b510a49cb573fd1ed67ba994c71fbb0fe7ea7c0b271799c`. Original cash, FIFO lots, authentication or account state were not copied into a simulated or production wallet. Only scoped valuation observations are normalized; the original financial receipts remain outside Git.

These receipts supply600 marks across25 exchanges, versus237 exchanges in the raw training universe. Therefore they do not support full-universe official valuation or qualification of a learned finalist. The implementation must remain explicit about that coverage gap, rather than silently trading only those25 contracts. No independent test, account request, production restart or STOP change occurred.

All600 nonzero position rows are consistent with YES-normalized six-decimal `currentPrice`, signed YES/NO quantities and cent-rounded reported `marketValue`. The validation allows at most half a cent of rounding per row; incorrect side orientation or larger disagreement fails. This orientation/rounding check is an observation about these receipts, not a claim that arbitrary future response versions were independently calibrated. Zero positions do not manufacture a mark, and a null mark for nonzero holdings explicitly removes availability. Observations retain their original receipt clocks and cannot be queried from future or other-role data. Normalized tape values are immutable.
