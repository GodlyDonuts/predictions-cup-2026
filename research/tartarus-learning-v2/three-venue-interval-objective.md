# Three-venue learning: uncertainty and actual accounting

The v6 learner's first exploratory finalist improves conditional external-reference marks but realizes modeled FIFO losses in its first window. Reference outperformance is insufficient evidence of a profitable replacement. See the separate checkpoint0007accounting audit; the frozen original lock is preserved.

The new receipt adapters retain Kalshi and Polymarket bid/ask intervals rather than discarding spread uncertainty. Each original body hash, binary token, market identity, party orientation and availability clock is checked. A Polymarket No token and a SIG No-side mapping each invert the entire interval once. Race-context-only/unknown-side links are excluded. Empty books emit explicit reference gaps, rather than zero or midpoint prices. These remain conditional party references: identical settlement and SIG price convergence are not established.

The new interval-HOLD reward evaluates both complementary sides under one YES probability per contract. For position differences dy,dn, the exact relative value is cash_difference + dn*1000000 + (dy-dn)*p. Its lower/upper values choose the appropriate bid/ask endpoint for each net exposure. Identical unmarked holdings cancel algebraically without inventing absolute wealth. Changed exposure with no interval stays unavailable. Reserved cash is already included in cash; cancellation cannot manufacture profit. This is a conditional valuation bound, not executable liquidation, realized P&L or an arbitrage guarantee.

Ten checks cover endpoint bounds, complementary YES/NO exposures, midpoint gains that reverse within the spread, missing-mark recovery, reservation accounting, exact source receipts, orientation and empty-book gaps. The adapters also decode actual retained latest receipts from both collectors. These helpers are not yet wired into the active frozen v6 training job; its original sources and results remain intact. The next training dataset and feature integration must carry their spread fields and explicit valuation semantics.
