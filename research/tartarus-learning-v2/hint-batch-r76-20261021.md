# Batch read-only exit hint validation

R74 resumed trading and filled two new orders, but it has not reached one distinct filled order per minute. The dispatcher separately called `existing_exit_hint` for each managed market. Each call performed the same whole-cohort history/ownership check, with no intervening mutation of Session, dispatch log or cohort policy. Fourteen configured scopes could repeat that check fourteen times during a single selection pass.

R76 performs that common validation once, then evaluates eligible scopes through the same private hint logic. The worker retains exact busy-target filtering and the special retry nomination for an untouched passive reservation. It captures one observation time for the read-only batch. Actual preflight, plan preparation, durable intent and physical dispatch independently verify their current state and clocks; a hint grants no order authority. The original single-hint method remains available and the worker tests compare both paths for existing reservations, stale books, revocation, expiry and unknown attempts.
