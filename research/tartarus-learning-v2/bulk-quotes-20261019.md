# Paid bulk and singular price observations

The optional v8 paper profile gives a policy the SIG price-only read surface as well as full-depth books. It can request one exchange, use an existing group of up to100 exchanges, or build an arbitrary ordered packet through local add/remove/clear actions. Duplicate IDs and ordering remain observable. One packet costs one admission through the existing serialized SIG read budget; there is no free background polling. The100-ID packet maximum comes from the endpoint, not a portfolio or decision restriction.

The source is the saved official v1 OpenAPI document, SHA256 `fbdf23e54d317392f9fb4a659b9511a01fad065e7a384f28091ef04894a732c9`: `GET /exchanges/prices` and `GET /exchanges/{id}/price`. This is a cached schema reference, not a fresh claim that production documentation or the exchange has been queried. Prices are represented internally as integer micro-units, rather than pretending this internal response is a byte-for-byte HTTP DTO.

## Information and replay boundaries

Quotes capture the counterfactual world at request time and become visible only on the delayed receipt. Receipt events wake a waiting model. Newer requests take precedence over older responses, and failed requests preserve the old quote cache. Missing IDs follow resolved scoped membership; an unknown historical book is not silently converted into an absent exchange. Missing/invalid historical books produce an explicitly modeled503 source-unavailable response. That conservative replay choice is not evidence that a live request actually failed.

Bid/ask use the remaining external displayed levels and unexpired counterfactual own resting quotes, normalized to YES. Quotes have no depth quantities. They never populate or renew delivered full-depth books, reveal cash or positions, refresh collateral advance, or execute orders. Models retain both quote and depth age information independently.

Latest price uses the latest already available recorded print or a later counterfactual own fill. It is null when neither exists; no midpoint or unrelated venue price substitutes for it. Recorded trade reporting may omit or delay true engine executions, and simultaneous original-versus-counterfactual matching has an explicit replay ordering. Option text is null because this adapter has no verified option-description source. `_projection_complete=false` records those limitations. Therefore this is not full calibrated parity with the authoritative exchange quote projection.

Enable with `bulk_quote_observations=true`, `observation_protocol="sig_scoped_bulk_quotes_v7"` and the existing component/order/query/full-depth profile flags. A component-v7 founder needs explicit `migrate_bulk_quotes=true` and observation-protocol migration; the policy becomes `tartarus-raw-api-bulk-quotes-gru-v8`. All tensors transfer exactly, but optimizer state, trajectories and scores start afresh. Older frozen workers and checkpoints retain their original semantics. Earlier architecture migrations are applied only to their exact parent types, so a component founder is not incorrectly routed back through the owned-order migration.
