# Packed historical price indexes: exact source parity

Both audited Polymarket partitions now have separate24-byte binary source-time indexes:22,396,189TRAIN samples/537,508,536bytes, and2,161,404EVO samples/51,873,696bytes, each covering378assets. Construction took20.03seconds and2.36seconds respectively. An independent decoder subsequently verified every binary record, file hash, receipt reference, source-time boundary, sample-only flag and normalized sample digest against the original receipt audits. [Actual proof](historical-price-index-20261020.json); [exact verifier bytes](historical-price-index-20261020-verifier.mjs.gz).

The layout is little-endian int64source milliseconds, original JS float64sample price, uint32receipt index and uint32sample-only flag. This preserves the exact original IEEE sample bits; it does not convert sampled observations into exact financial amounts. Each asset has its own file hash. The receipt table retains original file/body hashes, query bounds and actual request/retrieval clocks. The final manifest is written only after output read-back hashes and original audited normalized/inventory digests match. Failed builds retain incomplete evidence and cannot clobber a previous output directory.

On warm single-asset data, one million source-time binary lookups took672.83ms for the training asset and540.31ms for the evolution asset. This is an isolated CPU lookup benchmark, **not end-to-end replay/training speed** or a GPU utilization measurement. It demonstrates that repeated JSON parsing need not be on that future lookup path. No CUDA operation or second learner was started.

`sampleAtSourceTime` is deliberately a source-time query. It provides no historical `available_at` clock. Today's retrieval time cannot be relabeled as historical delivery, and a sample price cannot become BBO, depth, liquidity or a guaranteed fill. A future causal replay adapter must explicitly model provider availability, rate-limited delivery and mapping eligibility before this artifact can enter training. Both manifests remain `trainingAdmitted=false`, with independent test untouched by this index job. Current GPU021 still uses its original shorter dataset; this build has not silently changed its source, inputs or experiment identity.
