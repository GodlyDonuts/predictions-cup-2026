# Independent case sampling with batched frozen-model encoding

`batched_evaluation=true` enables a separate evaluation-only runner. It batches the contract encoder and recurrent computation across live cases, then samples each case's action heads from its own seeded CPU/CUDA RNG state. Padding is removed before sampling so another case's entity count cannot change categorical random-number consumption. The ambient RNG is restored afterward. Finished cases leave subsequent inference batches. No training frames or optimizer are created.

Each case retains its own account, API budgets, clock, hidden memory, decision counters and terminal result. Evaluation still requires initial wealth, scheduled exact daily boundaries and terminal wealth. It does not invent intermediate marks for early fills or use a training-shaped dense reward. The existing serial path remains the default and the independent-test source/calendar gates remain outside the compute choice.
