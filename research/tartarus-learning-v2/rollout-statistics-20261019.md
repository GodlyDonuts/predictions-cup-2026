# Compact training rollout statistics

The optional `compact_rollout_statistics=true` profile keeps the exact sampled actions, complete joint old log probability, critic value and recurrent state required by current PPO frames. It omits acting-time entropy and auxiliary monetary-quantile/success predictions, which those frames do not consume. The teacher-forced PPO forward still computes its full entropy and loss normally. This does not remove entropy regularization, change the reward, restrict actions, alter observations or reduce decision frequency.

`step_rollout` is a no-gradient collection API, not a substitute for the gradient/teacher forward. A separate no-gradient `bootstrap_value` encodes the same observation and hidden state and evaluates the critic without computing unused action heads. It leaves the carried hidden state, RNG, virtual clock and account unchanged. Full sampling/value computation remains the default. Compact mode is explicit in experiment configuration, propagates through finished-world compaction, and is prohibited for a serial stream without training capture. The existing actions-only evaluation option is separate.

Like the actions-only path, compact collection explicitly rejects non-finite Beta concentrations before dispatch. Old statistics, gradients and sampling behavior on valid finite parameters match; an invalid forward cannot advance the financial simulation. No policy parameters, checkpoint architecture or new behavior probability formula is introduced. Historical trajectories are not being relabeled or reset into profit.
