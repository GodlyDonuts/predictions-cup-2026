# Correcting the probability of the bot's own memory

The full-depth observation includes the previous raw action: family, target identity, side, price, patience, quantity and clock fractions, and query filter/time fractions. These samples can influence the next recurrent decision even when the API ignores them. V3/V4 PPO omitted the probability of several such fields outside their physical API operations. That omitted part of the trajectory score. Longer training cannot repair an incorrectly scored policy gradient.

`JointMemoryPolicy` (architecture v5, protocol `sig_scoped_local_memory_joint_v4`) scores every exposed sampled latent. It keeps the original conditional sampling law and all legal choices. Equal parameters plus equal random state produce identical actions, hidden state and subsequent random state; only the likelihood/entropy calculation changes. No raw action memory, quantity domain or API action is removed. Continuous latent probabilities describe the augmented sampled policy, including information later rounded into observations; they are not claimed to be the marginal probability of an exchange order.

Checkpoint architectures remain distinct, and old architectures retain their original likelihood semantics. Streamed and sealed-episode updates now verify architecture, observation protocol, state encoding and density identity as well as parameters; equal-weight v4/v5 models cannot reuse each other's likelihoods.
