The collector can temporarily prioritize existing source-bound and owned-risk books using the restricted runtime file `COLLECTION_PROFIT_SPRINT`. Its exact fields are `schemaVersion:1`, `owner:"Codex"`, `mode:"source_bound_and_owned_risk"`, `createdAt` and `expiresAt` in UTC, with a maximum one-hour lifetime. It is an operator scheduling setting, never an execution activation or rate-budget increase. No setting is created by the implementation itself.

The setting applies only while valid scoped paper/official risk exists, the existing bulk entry drain remains present, no separate maker/pair host is active, and every active passive wallet is demonstrably flat with zero reserve and no unresolved quote. Unknown liabilities or expiry restore ordinary collection. It retains source-bound research opportunities and owned/pending inventory in the frozen book plan, removes only unrelated discovery slots, rotates one existing bulk-price batch instead of all three, and omits unused tape/history reads. Pending production metadata still consumes its existing auxiliary slot. Positions, paginated orders, fresh account eligibility, account extras and realtime recovery remain in place.

At most four ordinary books still use depth20. The same serialized client enforces rolling60 reads/24 writes, completion pacing and durable Retry-After. Source/research age checks and immutable publisher/accounting semantics are unchanged. All source cohorts, archived banks, journals and operator stop/drain files remain intact. Paper-owned/pending risk now also suppresses the caller's idle floor, as official risk already did; admission/backoff remains authoritative.

Real-runner integration checks verify two source holdings receive their original depth20 books, positions reconciliation is retained, bulk collection rotates one batch, and ordinary behavior remains unchanged without the setting. This is correctness evidence. Expected removal of five unnecessary requests per cycle is a scheduling hypothesis; record subsequent timing before claiming a measured speedup or any profit.
