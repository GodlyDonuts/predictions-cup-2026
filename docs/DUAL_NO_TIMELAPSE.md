# Accelerated chronological dual-NO replay

`node data/replay-dual-no-timelapse-20261005.mjs --development` processes the existing sealed public-book and sanitized account-eligibility journals with a virtual clock. It makes no API requests and never sleeps for simulated latency. It advances the original frozen sequential paper policy only as each recorded receipt becomes available; later requests still must satisfy the two-second latency, one-percent depth, exact reservations and price limits. Publication scope, hash chain, epochs and nanosecond source versions are verified before use.

This is replay throughput, not execution speed or profit.

Missing observations remain censored; no quotes are interpolated, no current account snapshot is copied backward, and no settlement payout is invented.

The optional historical-development result transports today's exact reviewed rules backward and extends only the development review clocks/age. That assumption is explicit; the rules were not verified as known in those historical hours. It preserves the actual fill/risk/cash policy and causal recorded account gates. It is not held-out profitability proof and is not activation authority. The historical run currently yields the same two subsequent purchases and zero closed profit.

Parameters `--runtime`, `--cohort`, `--markets` and `--out` allow reuse with another frozen cohort. Markets must exactly match that bank's reviewed legs; the script cannot silently substitute predicates. Original bank and live wallet journals are read-only. The generated report records source-prefix hashes, sealed byte counts, frozen code identity, exact journal parity, coverage gaps, account ages, unresolved inventory, full losses and throughput.

Six driver checks cover deterministic later-request fills/exits and cash conservation, rejection of future account backfill, exact journal-state tamper detection, explicit historical transport, and actual eligibility-publication availability. Their synthetic successful exit is a correctness fixture, never an empirical profitability result.
