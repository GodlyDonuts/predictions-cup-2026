# Funded fundamental-value paper strategy

The former Texas Governor cohort buys on an election-settlement estimate but sells using a two-day holding limit and a price-only stop. That is a different hypothesis from fundamental investing. Both original wallets and every attributed fill remain intact. The separate `texas-governor-fundamental-20261005-v1` cohort connects the existing Rust settlement-value policy to funded, prospective wallets and the single collector.

A quote that creates an intent cannot fill it. Cash, principal, reserved cost, inventory and realized P&L are checked against the entire fill ledger.

The holding policy has no fixed holding timeout or price-only stop. It proposes an exit when the conservative executable bid reaches the supplied upper valuation scenario. Invalid or expired research blocks acquisition and requests review without erasing held risk. A calendar deadline does not generate a settlement payout. Receiving fresh valuation evidence requires a separately identified revision that preserves any existing inventory; merely changing a bank file is rejected.

The collector hosts the wallet in its existing process and shares the Governor book already collected for the prior cohort. It adds no permanent worker, read client or book slot. The original source prefix is checked by a pinned Rust binary; each later record and account-eligibility checkpoint enters a durable hash chain. Restart replays exact original inputs and the frozen model/code graph. Raw account values and credentials never enter this journal.
