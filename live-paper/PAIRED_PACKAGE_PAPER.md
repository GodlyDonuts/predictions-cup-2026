# Prospective sequential package wallet

`paired-package-watch.mjs` reads the existing sole collector's verified `public-books.jsonl`. It has no credentials, API client or order transport. A new cohort freezes its source prefix, future cutoff, policy and seven code identities; original studies are unchanged. Restart reproduces journal checkpoints before consuming new source rows. STOP, source closure, identity changes and broken journals fail closed.

The fixed experiment covers NH market381/exchange1070 and market382/exchange1071. Scoped contract metadata observed October2 identifies the same race, stage and election date with different winning parties. That supports **conditional normal mutual exclusion**; it is not proof of engine relationship protection, refund compatibility, force-settlement behavior or current execution readiness. The official [settlement guide](https://sig.thesuper.market/docs/settlement-and-payouts) specifies winning payout1, losing payout0, cost refunds for cancelled/N/A outcomes and administrator overrides. The capture's120second validity is not extended by this experiment. No current order authority is inferred.

Two fresh paired observations must independently update both book versions. Quote age≤20seconds and inter-leg skew≤3seconds. Each NO buy costs1−YES bid plus one adverse .005tick. Hard limits must leave at least .010/share conditional normal settlement margin. Initial sizing≤6shares,≤6SUSQ package reservation,≤5SUSQ principal on either unmatched leg,≤25SUSQ held basis and≤100SUSQ cumulative purchases. Added fees are zero.

The expensive leg is attempted first. Hypothetical execution requires a new source version from a request started at least2seconds after the durable decision, within30second intent lifetime, crossing the hard limit, and at most1% of each displayed depth level. A source version cannot be consumed twice by an intent. After the first intent ends, the second is sized to actual filled units; its decision time is actual consumer availability. Source rows in that same batch cannot backdate a second-leg fill.

If the second leg expires partially or unfilled, matched units remain held and only the surplus is offered for hypothetical liquidation. A new independent request is required for that exit too. A failed exit remains explicit unresolved orphan inventory and may be repriced on a new fresh quote. Stale/missing depth never becomes an invented sale. SELL accounting uses average held basis within each identical contract; it remains separate from conditional settlement scenarios.

The report separates cash, realized PnL, executable-depth liquidation PnL and conditional normal settlement PnL. Buying the pair generally starts with negative liquidation PnL because closing crosses two spreads. A conditional future gain is not realized earnings. Refund/override scenarios can lose principal; price discrepancy alone is not risk-free arbitrage. Sparse recorded snapshots do not prove continuous liquidity or simultaneous fills, and separate hypothetical wallets do not have additive capacity.
